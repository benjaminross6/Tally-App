# V1.1 Bugs

## Dragging

### Three bar icon

#### Bug

There is a three bar drag icon on both sides of each tally, which is weird.

#### Solution

Remove the drag icon on the right side, keep the one on the left.

### Hitbox

#### Bug

Holding down the tally often goes into drag mode rather than full screen. 

#### Solution

Limit the drag hitbox to just the three bar icon.

### Dragging in Sort Mode

#### Bug

Holding down a tally when sort is toggled makes the tally sortable. This shouldn’t be possible, as sort mode should be deterministic and have one order.

#### Solution

Disallow dragging and manual sorting in sort mode.

## Pins

### Pin Sorting

#### Bug

After pinning a tally, it can be moved anywhere in the tally list.

#### Solution

No unpinned tally should come before a pinned tally. Pinned tallies can be moved anywhere within after pinned tallies, and same for unpinned tallies. All pinned tallies come first, followed by unpinned tallies. Do not allow the user to drag a pinned tally below an unpinned tally. Display a pinned icon for pinned tallies above the three-bar icon on the left side of the tally. The drag icon will shift down a bit, and will fit with the pin left of the tally.
